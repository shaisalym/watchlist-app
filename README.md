WATCHLIST

---

This is a simple mobile app that lets you manage your personal movie watchlist. Built with React Native (using Expo), Expo Router for navigation, NativeWind for styling, and Zustand for state management.

---

FEATURES

- Add movies with title and poster URL
- Mark movies as "watched"
- When a movie is marked as watched, the app will automatically remove it from the list
- Toggle between light and dark mode. (Dark mode is default)
- Global state using Zustand
- Routing and layout handled with Expo Router

---

RUNNING THE APP

Requirements:

- Node.js
- pnpm or npm
- Expo CLI (`npm install -g expo-cli`)
- iOS Simulator or Expo Go app

To run locally:
'pnpm install'
'pnpm ios'
