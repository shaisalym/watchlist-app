WATCHLIST

---

This is a simple mobile app that lets you manage your personal movie watchlist. It is built using React Native, Expo Router, Tailwind (NativeWind), and Zustand for state management.

---

FEATURES

- Add movies with title and poster URL
- Mark movies as "watched"
- When a movie is marked as watched, the app will automatically remove it from the list
- Toggle between light and dark mode. (Dark mode is default)
- Global state using Zustand
- Expo Router provides a persistent layout

---

RUNNING THE APP

Requirements:

- Node.js and pnpm or npm
- Expo CLI (`npm install -g expo-cli`)
- iOS Simulator

Run:
'pnpm install'
'pnpm ios'
